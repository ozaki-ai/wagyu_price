# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

リモートリポジトリは作成物ごとに作るネット上で共有できる保管場所

ローカルリポジトリは作成物ごとに作る個々のPC上の保管場所


## プッシュとマージの違いは何でしょうか？

プッシュはローカルリポジトリをリモートリポジトリに反映させる

マージはブランチの統合


## コミットとプッシュの違い

コミットは変更内容を履歴として保存すること

プッシュはローカルリポジトリでの変更をリモートリポジトリに反映させる


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

どんな作業を行ったかがわかるようにする


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

ローカルは作業したブランチをmasterブランチへ統合させてかたリモートにプッシュする

プルリクエストはリモートでマージさせることで確認者がレビューできる、ローカルリポジトリの方ではマージされていないのでリモートからローカルに反映させる


## コンフリクトを起こしてしまった場合、どう対処すべきですか？

git statusで状況確認して、先にマージする内容を取り込むか、後にマージする内容を取り組むか、両方マージするパターンがあるので状況によって適切なパターンを選択する
